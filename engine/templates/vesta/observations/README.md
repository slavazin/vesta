# Observations

This folder holds observations: short notes of one thing a session noticed — something that cost effort,
surprised, was corrected, or was missed. An observation proposes nothing and binds no one.

It is a ledger: an observation is fixed once written. It changes only by receiving its closing
disposition and moving from `open/` to `archive/`.

**Who reads it.** The learn pass alone. A working session writes observations and never reads them: a
session that reads the pile grades its own noticing, and pays more at every start.

**How an observation enters.** A session writes it at its close, on its own authority, through the
engine's `obs add` command. No approval is needed, because it decides nothing.

**How an observation leaves.** It does not. A learn pass, or a decided proposal that used it, gives it a
closing disposition and moves it to `archive/`. An archived observation is never deleted.

`SCHEMA.md` says how to write one.
